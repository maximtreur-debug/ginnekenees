Over dit project

Ruimteverdediger is een kleine, gratis browsergame gebouwd met puur HTML, CSS en JavaScript — geen frameworks, geen installaties, geen accounts nodig.

Techniek

🖼️ HTML5 Canvas

Het spel zelf wordt getekend op een canvas-element, volledig in JavaScript.

🎨 Losse stylesheet

Eén gedeeld CSS-bestand zorgt voor een consistente look op alle pagina's.

💾 LocalStorage

Scores worden lokaal in je browser bewaard — er is geen server of database nodig.

Bestandsstructuur

ruimte-website/
├── index.html      (homepage)
├── spel.html       (het spel)
├── uitleg.html     (besturing & regels)
├── scores.html     (jouw scores)
├── over.html       (deze pagina)
├── css/
│   └── style.css   (gedeelde opmaak)
└── js/
    └── game.js     (spellogica)

Je kunt deze site direct hosten op elke statische hostingdienst, zoals GitHub Pages, Netlify of Vercel — er is geen server-side code nodig.
